Section 1 • Executive Overview

1. Corporate Overview & Vision

AnsoTech Digital Systems is a technology engineering firm based in Kampala, Uganda. The organization operates at the intersection of enterprise software development and secure network infrastructure management, catering to commercial enterprises, microfinance organizations, educational institutions, and public sector organizations.

Core Capability Statement

AnsoTech delivers end-to-end digital transformation—ranging from high-performance React/Node.js web portals and PostgreSQL databases to physical multi-building Cisco campus network designs and automated Wazuh SIEM security monitoring.

1.1 Organizational Structure

Our operational model is segmented into two main technical divisions that collaborate on integrated client projects:

  • Software Systems Division: Focuses on full-stack web applications, REST API integration, database schema optimization (PostgreSQL, MongoDB, SQL Server), and modern responsive UI design.
  • Network & Infrastructure Division: Oversees physical/virtual network topology planning, Cisco switch configuration (VLANs, STP, EtherChannel), hypervisor management (VMware/Ubuntu), and cybersecurity threat monitoring.

1.2 Engineering Philosophy

Every system deployed by AnsoTech adheres to three non-negotiable standards:

  1. Scalability by Default: Code bases and network addressing schemes are engineered to accommodate 10x growth without refactoring.
  2. Data Integrity & ACID Compliance: Financial, medical, and operational record systems use strict relational constraints to prevent data corruption.
  3. Proactive Security: Threat prevention, access control lists (ACLs), and automated SIEM auditing are built into the network design rather than added after deployment.

4.1 VLAN Segmentation & Topology Planning

To reduce broadcast domains and secure inter-departmental communications, networks are segmented into dedicated Virtual LANs:

VLAN ID Subnet Allocation Department / Usage Security Access Level
VLAN 10 192.168.10.0/24 Corporate Administration High (Restricted Access)
VLAN 20 192.168.20.0/24 Finance & Payroll Systems Critical (Isolated)
VLAN 30 192.168.30.0/24 Staff & Workstations Medium (Filtered Internet)
VLAN 40 10.0.40.0/22 Guest Wi-Fi Access Low (Internet Only / No LAN)

4.2 Layer 2 & Layer 3 Protocols

  • Spanning Tree Protocol (STP) & PortFast: Preventing switching loops while enabling rapid port transition for edge user devices.
  • EtherChannel Link Aggregation: Bundling multiple physical trunk links into single logical links to maximize bandwidth and provide hardware redundancy.
  • Inter-VLAN Routing & ACLs: Configuring Layer 3 switch interfaces and router Access Control Lists to enforce strict inter-departmental traffic rules.

Section 5 • Virtualization & Systems

5. Virtualization & System Administration

AnsoTech builds host environment infrastructure that maximizes physical hardware utilization while ensuring isolated execution spaces for database instances, application servers, and security appliances.

5.1 Enterprise Hypervisor Deployment

We deploy virtualization technologies—specifically VMware Workstation Pro and VMware ESXi—to host multiple virtual machines on centralized server hardware.

  • Network Adapter Modes: Custom configuration of Bridged networking for publicly reachable instances and Host-Only networks for secure internal databases.
  • Virtual Disk Allocation: Dynamic thin provisioning and SCSI disk controller configurations for optimized I/O speeds.
  • Snapshot Management: Scheduled VM snapshots before critical updates to ensure zero-downtime rollbacks if configuration failures occur.

5.2 Linux Server Hardening (Ubuntu Server)

Ubuntu Server serves as our primary OS choice for running backend web platforms, reverse proxies, and cybersecurity software.

  • Reverse Proxying: Configuring Nginx as a reverse proxy for Node.js applications, handling SSL/TLS termination and load balancing.
  • Automated Backup Scripts: Cron-driven database dumps exported off-site via encrypted SSH file transfer protocols.

6.1 Core Security Capabilities

  • Log Analysis & Correlation: Centralizing log collection from switches, Linux servers, Windows workstations, and database engines into a unified search index.
  • Intrusion Detection (FIM): File Integrity Monitoring tracking unauthorized changes to critical system files (`/etc/passwd`, system binaries, registry keys).

  • Active Response Engine: Automatically executing IP block commands on firewalls when brute-force SSH or HTTP login attempts are detected.

Section 7 • Project Methodology

7. Engineering Methodology & Delivery Lifecycle

To ensure high standards and transparent milestone tracking across both software and network engineering projects, AnsoTech follows a structured 5-phase delivery model.

Phase 1: Discovery & Technical Requirements Gathering

Conducting detailed physical site surveys for network installations, or mapping out data models, user roles, and functional scope for software systems.

Phase 2: Architecture Blueprinting & Schema Design

Creating CAD network topology diagrams, dynamic IP addressing tables, database Entity-Relationship Diagrams (ERDs), and Figma application wireframes.

Phase 3: Core Implementation Sprint

Agile software development iterations combined with hardware provisioning, cable termination, switch flashing, and virtualization server installation.

Phase 4: Security Auditing & Quality Assurance

Executing stress tests, SQL injection checks, network vulnerability scans via Wazuh SIEM, and User Acceptance Testing (UAT) with key client stakeholders.

Phase 5: Production Deployment & Technical Handover

Final domain cutover, cloud deployment, physical network commissioning, complete documentation delivery, and administrator training sessions.
